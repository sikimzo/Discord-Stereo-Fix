# 🔊 New Discord Stereo Fix
A Simple Stereo Installer For Discord

## 💻 Installation steps
download the required files from release section

then extract the .zip file

run the Installer.bat file and select your discord (btw u can select discordptb and canary)

then open your Discord and you will be see that all the issues are fixed
